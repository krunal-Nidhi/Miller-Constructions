Miller Constructions Website & Rent vs Buy Simulator
======================================================

Included Files:
1. index.html - Complete standalone web application (React + Tailwind CSS + Interactive Simulator).

How to run locally:
- Simply double click `index.html` to open it directly in any web browser!

How to upload online (1-click via Netlify / Vercel / GitHub Pages):
1. Go to https://app.netlify.com/drop
2. Drag and drop this folder or the index.html file directly into your browser window.
3. Your website will instantly be launched live online with a free SSL link!
